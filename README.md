# ATS Resume Analyzer

AI-powered ATS Resume Analyzer built with Streamlit, NLP, Sentence Transformers, and Groq LLMs.

## Features

- ATS resume scoring
- Semantic similarity matching
- Keyword analysis
- Missing keyword detection
- AI-powered resume improvement
- PDF/DOCX resume parsing
- Download improved resume as DOCX/PDF

## Tech Stack

- Python
- Streamlit
- Sentence Transformers
- Scikit-learn
- Groq API
- NLP
- ReportLab
- PDFPlumber

## Deployment

Deployed using Streamlit Cloud.

## How It Works

1. Upload resume (PDF/DOCX)
2. Paste job description
3. Analyze ATS match score
4. Detect missing keywords
5. Improve resume using AI
6. Download optimized resume

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
